Complete 7-Step Pedagogical Architecture

From syllabus prerequisite mapping to measurable mastery gains.

01
Curriculum & Dependency Modeling: Lecturers structure Units, Topics, and Atomic Concepts, linking directed prerequisite relationships.
02
Question Authoring with Concept Tagging: Questions tagged with difficulty (Easy, Medium, Hard) and exact concept metadata.
03
Diagnostic Assessment Execution: Students take timed diagnostic assessments; responses are automatically scored per concept.
04
DAG Prerequisite Traversal Engine: NetworkX algorithm climbs upstream dependency trees to uncover root causes behind failing concepts.
05
Interactive Knowledge Map Rendering: Visual Cytoscape directed graph with real-time status color codes, zoom controls, and inspection drawer.
06
Topological Learning Path Synthesis: Topological sort schedules prerequisite foundations before higher-order topics with code guides.
07
Follow-Up Validation & Cohort Analytics: Re-test validates observed learning gains while faculty dashboard displays class-wide analytics.
